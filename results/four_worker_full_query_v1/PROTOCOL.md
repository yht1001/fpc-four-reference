# 四参考六条 Query 评测

沿用已完成的四参考实验的四套参考、模型、原始 0.5 秒网格及全部七组锁定参数，无新增校准。原 V4 的概率按请求内容哈希重用，仅补推其他视频。主比较为四参考与事前指定的 V1+V2，其他双参考组合同时评分。

按窗口剔除与四条 Demo 源文件重合的内容。对四条完整 Demo 源文件及六条原始 Query 源文件扫描 JPEG 与解码 RGB 的 SHA-256，结合源路径、帧索引和原始录像时间水印核对。若窗口目标范围、窗口上下文范围或实际采样包含重复帧，整窗剔除；时序解码及分段指标在剔除缺口处断开。不会仅因同一录制或外观组剔除无内容重合的片段。V2、V3 为同录像的不同 part，时间水印精度为秒，边界和实际参考／校准时间另核对。六条汇总为跨片段评测，单列 V4 录像隔离子集。Query GT 在新预测冻结后只用于评分。
